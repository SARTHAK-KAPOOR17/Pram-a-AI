# Pramāṇa AI

**Pramāṇa AI** is an AI-powered software testing and quality assurance platform designed to make automated tests more intelligent, reliable, and self-healing.

The platform uses **AI, browser automation, and intelligent failure analysis** to automatically generate test cases, execute them, identify the root cause of failures, and recover from common test breakages such as changed UI elements and outdated selectors.

When an automated test fails, Pramāṇa AI analyzes the test failure, DOM structure, screenshots, logs, and execution context to determine whether the problem is caused by the test, application, network, or environment. When a broken selector is detected, the system can identify a suitable replacement, assign a confidence score, and safely retry the test.

Beyond self-healing, Pramāṇa AI can transform **natural-language requirements into executable test cases**, detect flaky tests, perform visual regression analysis, generate intelligent bug reports, and integrate automated testing into CI/CD pipelines.

### Core Capabilities

- AI-powered test-case generation
- Natural language → executable Playwright tests
- Automated browser testing
- AI-based failure and root-cause analysis
- Self-healing test automation
- Intelligent selector generation
- Confidence-based healing
- Flaky-test detection
- Visual regression testing
- AI-generated bug reports
- API and UI testing
- Parallel test execution
- Cross-browser testing
- GitHub and CI/CD integration
- Test analytics and observability

### Technology Stack

**Frontend:** React.js, Vite, Tailwind CSS  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**Automation:** Playwright  
**AI:** LLM-based reasoning and analysis  
**DevOps:** Docker, GitHub Actions  
**Security:** JWT, RBAC, secure environment configuration

### Vision

**Pramāṇa AI aims to move software testing from simple automation toward intelligent verification—where tests can understand failures, adapt to application changes, and continuously improve their reliability.**
